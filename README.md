# ACE Fitness Website

A responsive, single-page website for ACE Fitness Centre for Strength & Conditioning in Bengaluru. Built with plain HTML, CSS, and JavaScript so it can be hosted on GitHub Pages without a build step.

## Files

```text
ace_fitness_website_bundle/
├── index.html
├── style.css
├── script.js
└── assets/
    ├── media/
    │   ├── ace-fitness-logo.png
    │   └── 19 gym photos
    └── reviews/
        └── 16 original Google review screenshots
```

## Preview locally

Open `index.html` in a browser. No package installation or build command is needed.

## Publish using GitHub Pages

1. Create a GitHub repository.
2. Upload the *contents* of this folder to the repository root. Keep `index.html`, `style.css`, `script.js`, and `assets/` together at the root level.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select branch `main`, select folder `/(root)`, and save.
5. Wait for the Pages deployment to finish, then open the URL shown on the Pages settings screen.

## Included features

- Responsive layout for desktop, tablet, and mobile screens
- ACE Fitness logo and supplied gym photography
- Original review screenshots shown as images, with no retyped review copy
- Image viewer with previous/next controls and Escape key support
- Mobile navigation and sticky mobile call button
- Click-to-call, WhatsApp, and Google Maps directions links
- Reduced-motion preference support
